## 1. Purpose & Background
Investigation of firmware upgrade failures on AST2600 dual-flash architecture when upgrading via WebUI HPM upload. During Rev 13.03 flashing, the backend `spx_restservice` daemon halted due to missing parameter checks.

## 2. Root Cause Analysis (RCA)
- **Root Cause**: Missing `preserve_config` parameter in initial HTTPS POST upload payload caused the backend C service daemon to reject preparation request.
- **Affected Subsystem**: AST2600 WebUI HPM Flashing Service (`spx_restservice`).
- **Fix Applied**: Explicit casting of `preserve_config` JSON parameter and fallback defaults.

## 3. Verification Matrix & Test Requirements
1. **Dual-Flash Bank Switch Test**: Validate secondary SPI Flash activation and image bank switching.
2. **REST API Payload Validation**: Verify `POST /api/v1/system/firmware/upload` with `preserve_config=true` returns HTTP 200.
3. **Stress & Memory Leak Verification**: Run 60-minute stress flashing loop without memory leaks.

## 4. API Specification & Endpoints
- `POST /api/v1/system/firmware/upload`
  - Headers: `Content-Type: application/json`
  - Payload: `{ "preserve_config": true, "image_bank": "inactive" }`
  - Expected Response: `HTTP 200 OK` with session ID.
